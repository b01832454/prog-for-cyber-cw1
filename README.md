Hello and welcome to the cybersecurity utilities program

To get started download the files, or if you are using the library as a stand alone type at the beginning of your file:
import security_tools 

once imported use the password variable or ip_address variable to check that parameter, please refer to the additional file if unable to get working correctly.


validate_password will check that the password meets criteria, minimum length, symbols, digits and uppercase. If this does not meet criteria it will suggest a strong password
validate_ip will check the ip address entered by the user meets the correct criteria, 3 dots, range 0-255, 4 octates etc
