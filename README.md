Welcome to the security tool

This has 3 different programs within it, once running it will give you an option to select 1-4

1 - Is the security event counter, program should ask for a password 10
times. There will be a correct password stored in a variable (admin) You need to
count the number of times correct and incorrect passwords are entered.
Also display the percentage of incorrect passwords entered and raise an
alert if this is more than 50%.

2 - Uses a predefined password (Cybersecurity). Allows a maximum
number of 5 attempts. Ask the user for a password guess. Count attempts.
Stops when the correct password is entered. Stops when the maximum
number of attempts is reached (5).

3 - Asks for a username and password. Check the
credentials (username - admin, password - student). Display whether authentication succeeded or failed. If it fails,
ask for the username and password again. Allow three failed logins. If
failed logins reach the maximum attempts, display a message that the
account is frozen for 24 hours.

4 - exits program
